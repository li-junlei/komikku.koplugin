# 实施方案与进度

## 目标

- Kindle Voyage，KOReader 2026.07.2。
- 接入已部署的公网 HTTPS Komga。
- 配置 Komga 即可独立使用同一个书架，阅读、收藏、移出收藏、新建分类与调整分类。
- WebDAV 为可选功能，与 Komikku 1.14.1 或其他设备合并 Komga 收藏、分类和进度；其他来源的消息保留。
- 保留个人配置入口；无需提供开发者账号密码。
- 同时支持在线加载和离线下载，使用原生阅读器，不进入 KOReader 历史。

## 结构

1. `km_proto.lua`：保留原始字段的最小 Protobuf wire 解析器。
2. `km_sync.lua`：解析书架、比较章节版本、仅补写进度字段，使用 ETag 条件写回。
3. `km_http.lua` / `km_komga.lua`：HTTPS、认证、证书验证及 Komga 页面 API。
4. `km_cache.lua`：章节清单、在线缓存、预取、可恢复离线下载与清理。
5. `km_document.lua`：把一章视为多页原生 MuPDF 图片文档，逐页接入 KOReader。
6. `km_history.lua`：仅拦截本插件目录的历史添加及关闭时间更新。
7. `km_app.lua` / `main.lua`：本地状态、设置、书架、章节菜单及阅读事件。
8. `km_catalog.lua` / `km_library.lua`：Komga 书库筛选、分页、条目与章节转换、来源选择、直接阅读及收藏管理。
9. `km_bookshelf.lua`：统一书架的条件同步、分类名映射、来源重定向和进度翻译。

影响范围包含插件入口、元数据、所有上述模块、自检、使用说明和安装包；不修改 KOReader 或手机 Komikku 的代码。

## 待安装后的验收

这些项目需要真实配置和设备，尚未以模拟检查代替：

1. 在 Voyage 上重启 KOReader，检查入口、中文、输入框、密码遮罩。
2. 用真实 WebDAV 同步；确认收藏、分类、章节数和手机一致。
3. 手机、Kindle 分别读一章；两边同步后核对页码、已读状态和冲突选择。
4. 在线读一章，检查原生缩放、裁边、横屏及 Voyage 翻页键。
5. 下载一章，关闭 Wi-Fi、重启 KOReader 后继续阅读。
6. 在普通书籍与漫画间切换、关闭、休眠和重启，检查漫画不在历史中，普通书籍历史未被修改。
7. 验证服务器条件写入、证书兼容性、网络失败和可用存储不足时的表现。
8. 0.1.1 新增验收：慢速下载时观察进度变化并取消、续传；漫画连续翻页全屏刷新，退出后普通书籍仍按原规则刷新。
9. 0.1.2 新增验收：切换列表/封面，翻页加载六本，分类筛选、最后一页、缺失封面、离线缓存、横竖屏和 Voyage 翻页键。
10. 0.1.3 新增验收：初始界面为 Bookshelf 时，从漫画阅读菜单和读完提示返回均落在 Bookshelf；普通书籍、切换章节、退出与重启保持原行为。具体安装版本的 Bookshelf 仍需实机验证。
11. 0.2.0 新增验收：与手机对照筛选结果，分别浏览系列/阅读列表/单本；直接阅读未收藏漫画、下载后离线打开、加入指定分类，然后手机同步检查条目、章节身份和阅读进度。自定义命名需两端一致。

## 刻意保留的边界

不实现 Android 扩展运行环境、非 Komga 来源、分类重命名或删除、独立漫画阅读 UI、额外桥接服务和自动跨章。后续仅在实机结果要求时调整预取、缓存或接口。
