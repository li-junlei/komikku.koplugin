# 0.3.2

- 漫画阅读菜单新增 **Komikku 漫画 → 漫画去灰**，默认关闭，切换立即生效并记住选择。
- 参考漫画一键去灰插件的自然增强参数，适配本插件图片渲染。仅处理漫画内容，不改变菜单、页脚、其他书籍或原始图片；夜间模式暂停，彩色缓冲区不处理。
- 去灰与原始页面分别缓存，避免翻页、缩放及重复绘制叠加效果。
- 调整发布说明文件名，兼容已安装版本更新器的路径检查。

可通过插件设置中的 **检查插件更新（GitHub）** 下载升级；也可手动解压 **komikku-koplugin-0.3.2.zip** 覆盖安装后重启。

37 项本地测试通过；Kindle Voyage 上的实际去灰效果与性能仍需实机确认。
