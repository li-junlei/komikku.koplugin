# 0.4.1

- 缺页下载移出阅读器绘制过程，在后台执行；打开章节和翻到未缓存页时显示可取消的下载进度框。
- 有总大小时显示百分比及下载字节；无总大小时显示已下载 KiB。复用正在下载的当前页，完成后重绘并刷新页面尺寸。
- 关闭本插件漫画的原生后续页预渲染，避免界面线程提前解码大图；保留低优先级、串行的后两页预下载，跳页时优先处理当前页。
- JPEG / PNG 获取原始数据，减少强制转换 PNG 带来的传输量；保留原始分辨率与质量，旧缓存不自动删除。
- 取消、失败或关闭阅读器会清理等待任务，不把未下载页记为已读。慢速单页下载允许约 5 分钟，可随时取消。

建议手动下载 **komikku-koplugin-0.4.1.zip**，解压覆盖 `koreader/plugins/` 中的插件目录并重启。配置、书架、离线下载和进度保留。

44 项本地测试通过，桌面 MuPDF 图片格式识别检查通过。Voyage 上的真实速度尚需验证；超大原图的最终解码仍受设备 CPU / 内存限制，可能短暂停顿。
