# 0.5.0

- 改为可独立使用的 Komga 客户端：只配置 Komga 即可浏览、筛选、预览封面、阅读、下载和加入书架，无需先同步手机或取得来源 ID。
- 始终只有一个书架，保留列表和每页六本的封面模式。支持加入或移出收藏、新建分类、更改收藏分类，以及从 Komga 刷新章节。
- 书架与进度先保存在设备，重启后继续使用。移出收藏保留进度和下载图片。
- WebDAV 改为可选：配置后在同一个书架中合并 Komga 收藏、分类和阅读进度；未配置时正常使用，清空 WebDAV 地址停用同步也不会清空书架。
- 首次同步可条件创建不存在的 `backup.proto`；目录需已存在。已有文件按强 ETag 条件写回，冲突、失败或取消时保留设备数据与队列。
- 默认采用官方 Komga 扩展第一个实例的来源 ID；同步已有手机书架时优先匹配手机来源，也可手动填写完整 ID。身份变动会保留旧下载和继续阅读的映射。
- 同步按 Komikku 的版本规则合并，保留远端书签、未知字段及非 Komga 来源；同步请求期间的新翻页进度不会被旧结果清除。
- 保留后台逐页下载及进度条、漫画全屏刷新、去灰、缓存管理、Bookshelf 返回和阅读记录隔离。

下载 **komikku-koplugin-0.5.0.zip**，退出 KOReader 后覆盖原插件目录并重启。现有配置、书架、进度和缓存继续保留，请勿删除 `koreader/komikku/` 或 `koreader/settings/komikku.lua`。

60 项本地测试及安装包检查通过，包含独立运行后重启、启停 WebDAV 时书架与进度保留、两客户端同步、来源与缓存身份映射、其他来源原样保留、版本冲突、条件创建失败和下载缓存复用。尚未进行 Kindle Voyage 与真实手机账号的端到端复测；手机使用其他 Komga 实例或扩展版本时，需确认来源 ID 正确匹配。
