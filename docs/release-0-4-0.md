# 0.4.0

- 同步集中至 **设置 → 同步**：WebDAV 设置、自动同步和立即同步；移除第一层及封面书架的同步按钮。
- **更新**移到第一层，进入后显示当前版本和检查更新按钮。修复返回文件管理器后仍提示漫画未关闭的问题。
- 呼出 KOReader **目录**即可选择上一章、重试当前章节、下一章，下方列出当前章节全部页码并标记当前页，可点击跳转。普通书籍目录不变。
- 继续阅读按钮动态显示 **继续阅读 — 漫画名**。
- **缓存管理**区分手动离线下载和在线缓存，显示页数与空间，支持逐章删除、继续下载和清空在线缓存；保留阅读进度与手机书架。
- 在线缓存上限默认 128 MiB，可设为 0–4096 MiB，0 关闭自动清理。优先逐章删除最早阅读、最久未再打开的在线缓存，保护当前章节和手动离线下载。旧缓存无阅读顺序记录时使用原图片时间排序。

可通过插件第一层 **更新 → 检查更新** 升级；旧版入口仍在设置中。也可手动解压 **komikku-koplugin-0.4.0.zip** 覆盖安装并重启。

40 项本地测试及安装包检查通过；新的目录、关闭处理和缓存管理尚未在 Kindle Voyage 实机验证。
