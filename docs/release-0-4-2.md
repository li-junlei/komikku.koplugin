# 0.4.2

- 本插件漫画不再写入 KOReader 内置阅读统计，因此不新增阅读日历、每日时间线、时长或页数记录；普通书籍与全局统计设置保持原样。
- 清除历史中已有的本插件路径条目，继续阻止新历史记录；本插件漫画不更新收藏列表最近阅读时间。
- 新增 **设置 → 清理本插件旧阅读记录**。先备份统计数据库，再按书籍设置中的文件指纹清理对应旧统计，失败会回退。保留同名普通书籍、漫画进度和 Komikku 同步数据。
- 原缓存和书籍设置都已丢失的旧统计无法确认归属，需在 KOReader 统计中手动删除；第三方独立日志未涵盖。

建议手动下载 **komikku-koplugin-0.4.2.zip**，覆盖插件目录并重启。若之前已在日历留下记录，升级后返回文件管理器，再使用上述清理入口。

47 项本地测试通过，含真实 SQLite 备份、准确匹配和故障回退验证；Kindle Voyage 上的实际日历表现尚需确认。
