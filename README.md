# Komikku / Komga for KOReader

面向 **Kindle Voyage / KOReader 2026.07.2 / Komikku 1.14.1** 的漫画插件测试版。

直接连接 Komga，并读写 Komikku 已有的 WebDAV 书架同步文件。无需安装 Android 扩展、无需另设桥接服务器。

[GitHub 仓库](https://github.com/li-junlei/komikku.koplugin) · [下载正式发布包](https://github.com/li-junlei/komikku.koplugin/releases/latest)

## 主要功能

- 读取手机收藏、分类、章节及阅读进度；支持从 Komga 书库新增收藏，分类的创建和已有收藏的编辑仍由手机管理。
- 直接浏览 Komga 书库，按手机 Komga 扩展相同规则搜索、筛选和排序，支持封面及列表显示。
- 按 Komikku 1.14.1 的章节 `version` 规则合并阅读进度：版本高者优先，相同版本保留 Kindle 的待同步进度。
- 在线逐页加载、后续 2 页预取、整章下载及离线阅读；下载中断后可继续。
- 使用 KOReader 原生分页阅读器和 MuPDF 图片后端，复用缩放、横屏、裁边等功能。
- 漫画进度在插件内保存并与手机同步，不加入 KOReader 内置历史、阅读统计、日历和时间线。
- 书架支持列表和每页六本的封面模式；Komga 书库列表按屏幕容量分页显示。
- 漫画阅读支持每页全屏刷新、可选去灰和目录跳页；缓存管理区分手动离线下载与在线缓存。
- 设置页面配置 Komga、WebDAV、同步目录、自动同步及可选的自定义 CA 证书。
- 自动同步：打开在线书架、关闭漫画、阅读时恢复联网或唤醒且已联网；也可手动同步。

这是可安装测试版。自动化检查通过不代表真实账号、Kindle 的 TLS 或原生绘制已获验证。

## 安装

1. 从 [GitHub Release](https://github.com/li-junlei/komikku.koplugin/releases/latest) 下载 `komikku-koplugin-版本号.zip`，将其中的 `komikku.koplugin` 文件夹复制到 Kindle 的 `koreader/plugins/`。不要使用 GitHub 自动生成的 Source code ZIP。
2. 重启 KOReader，在菜单中找到 **Komikku 漫画 → 设置**。
3. 填写 **Komga 连接**：HTTPS 地址、用户名、密码。地址可带反向代理的路径前缀。
4. 在 **设置 → 同步 → WebDAV 同步设置** 中填写：与手机相同的 HTTPS 基础地址、用户名、密码和同步目录。目录单独填写，留空表示基础地址根目录；不要把 `backup.proto` 写入地址或目录。
5. 在 Komikku 1.14.1 中启用书架、分类、章节同步，并执行一次同步。然后选择插件的 **设置 → 同步 → 立即同步**。

例如手机 WebDAV 基础地址为 `https://dav.example/dav`，同步目录为 `komikku`，插件使用的文件就是 `https://dav.example/dav/komikku/backup.proto`。目录中的空格和中文由插件编码。

账号信息仅在设备本地的 `koreader/settings/komikku.lua` 保存，密码输入框会遮罩，但设置文件本身为明文。安装包不包含任何账号信息。请保管设备及备份。

## 更新

版本更新说明见 [GitHub Release](https://github.com/li-junlei/komikku.koplugin/releases)。

- **手动更新**：退出 KOReader，用最新安装包中的 `komikku.koplugin` 覆盖同名插件目录，再启动 KOReader。配置、书架、缓存和阅读进度保存在插件目录之外；不要删除 `koreader/komikku/` 或 `koreader/settings/komikku.lua`。
- **插件内更新**：关闭漫画并等待同步完成，打开第一层的 **更新 → 检查更新**。确认后下载，显示可取消的进度条；校验安装包后安装并提示重启。无需 GitHub 账号或令牌。
- Kindle 无法稳定访问 GitHub 时，可在电脑下载后手动更新。安装时请勿断电；自动更新保留旧目录 `komikku.koplugin.previous`，必要时可恢复或重新解压安装包。

## 浏览 Komga 书库与加入收藏

1. 书库直接访问设置中的 Komga 地址，不需要选择服务器或先同步手机书架。打开漫画及加入手机书架时，会自动匹配已同步的 Komga 来源；需要手机书架中至少有一部该来源的漫画，以取得正确的来源 ID。
2. 打开 **浏览 Komga 书库**。点击搜索或筛选，设置完成后选择 **应用筛选**。筛选和排序会保存；它们不会自动读取或修改手机当前的筛选选择。
3. 点击条目或封面，选择 **阅读 / 章节列表**、**简介** 或 **加入 Komikku 书架**。新收藏可选择已有分类，不会新建分类；已有收藏不会被重复加入或重新分配分类。
4. 手机上执行 WebDAV 同步后，即可取得 Kindle 新增的收藏与进度。上传结果不确定时不要假定已加入，可先重新同步确认，或者再点加入；操作会先重新检查远端。

自动匹配失败时，打开 **设置 → Komga 同步来源**，直接选择手机书架中可正常阅读的 Komga 漫画对应的来源。列表显示完整十进制来源 ID，也可手动填写；只接受已同步书架中的 ID，避免将收藏写入错误来源。选择后固定使用该来源，所有网络访问仍使用设置中的 Komga 地址。恢复“自动匹配”即可取消指定。

筛选语义与已核对的手机扩展一致：

| 筛选 | 行为 |
|---|---|
| 未读 | 同时请求 `UNREAD` 和 `IN_PROGRESS` |
| 阅读中 / 已读 | 分别请求 `IN_PROGRESS` / `READ`，可组合勾选 |
| 查找类型 | 系列、阅读列表、单本 |
| 合集 | 指定合集后查询该合集的系列，优先于查找类型 |
| 书库、状态、题材、标签、出版社 | 多选，同组值以逗号连接 |
| 作者 | 按服务器返回的角色分组，每位作者单独发送 `name,role` |
| 排序 | 相关度、字母顺序、添加日期、更新日期、随机；可倒序 |

“已读”筛选读取 **Komga 服务端** 的阅读状态，与手机扩展的查询一致；不会把插件本地进度当作服务端状态，也不会修改 Komga 服务端的已读状态。

如果手机自定义过 Komga 扩展的 **Chapter name template** 或 **Scanlator seperator**，请在书库的 **筛选 → 章节命名（与手机一致）** 中填写相同内容。默认是 `{number} - {title} ({size})` 和逗号。模板允许 `{title}`、`{seriesTitle}`、`{number}`、`{createdDate}`、`{releaseDate}`、`{size}`、`{sizeBytes}`；命名不一致可能导致后续按章节组合键同步时无法匹配。

本地浏览记录在 `koreader/komikku/catalog.proto`，与 Komga 地址及用户名关联；未收藏的阅读进度单独保存在 `progress.lua` 的本地记录中，不进入 WebDAV 待同步队列。下载仍可从“缓存管理 → 手动离线下载”进入。

## 阅读与下载

- **打开书架**：联网时默认先同步；离线时使用最后保存的书架。
- 选择漫画后，进入章节列表，再选 **阅读 / 继续阅读** 或 **下载整章**。
- 在线缓存不等于离线下载；只有“离线下载”中标为“已下载”的章节保证整章在本地。
- 整章下载期间显示完成页数、百分比和当前页已接收的数据量。进度按完整页面计算，不用未知图片大小估算剩余时间；点击进度对话框可取消。
- 阅读途中呼出 KOReader 的 **目录**，可选择 **上一章 / 重试当前章节 / 下一章**，以及当前章节的任意页码。
- 插件不会自动跨章翻页；每章内使用 KOReader 的操作。
- 离线阅读先保存本地进度，下次联网再回传。手机需再次同步，才能读取 Kindle 写入的进度。
- 在线缓存默认上限 128 MiB，可在缓存管理中修改或关闭，按最早阅读顺序逐章清理；当前章节受保护，可能暂时超过上限。正式离线下载由用户手动删除。
- 加载失败时显示错误页，不把错误页当作已阅读。检查网络后从阅读器目录中重试当前章节。

阅读页面尚未缓存时显示可取消的进度框，下载在后台执行，绘制过程不发起网络请求；原生后续页渲染提示仅对本插件漫画关闭。后台串行预取后续 2 页。网络很差或原图非常大时仍可提前下载整章；原始大图的最终解码仍可能耗时。

## 阅读设置与记录

- 本插件漫画在打开和翻页时请求全屏刷新，普通书籍继续使用原有刷新规则。
- 阅读时打开 **Komikku 漫画 → 漫画去灰** 切换增强效果，选择会记住。仅处理灰度页面，夜间模式暂停；参数参考[漫画一键去灰插件](https://gitee.com/gerenshiyongtyy/koreadermanhuayijianquhui)。
- 返回文件管理器视为关闭漫画。若 KOReader 初始界面设为 Bookshelf，会返回 Bookshelf；不可用时返回文件浏览器。
- 插件自己的继续阅读、页面位置和 WebDAV 同步进度正常保存，漫画不写入 KOReader 内置阅读记录。
- 已存在的漫画统计可在 **设置 → 清理本插件旧阅读记录** 中清理。插件先备份统计数据库，再按缓存目录中书籍设置的 MD5 指纹清理，不按漫画名称模糊删除。备份位于 `koreader/komikku/statistics-before-clean-日期时间.sqlite3`；旧缓存及书籍设置均已丢失的记录需手动处理。

## 同步保护

- 每次回传前重新 GET 完整 `backup.proto`，不从旧书架重建或覆盖手机收藏、分类、设置、书签。
- 保留未编辑的原始 Protobuf 字段，包含未知字段和完整 64 位来源 ID。
- 常规进度同步只修改对应章节的 `read`、`lastPageRead`、`lastModifiedAt`、`version`。用户明确选择“加入书架”时才新增漫画消息，或更新该条目的收藏、加入时间、版本和所选分类。
- 写入前在本地保存 `koreader/komikku/remote-before-write.proto`；书架缓存为 `shelf.proto`，待同步进度为 `progress.lua`。
- PUT 使用服务器返回的原始强 ETag，保留引号。缺少强 ETag 时可读取书架，但暂停回传。
- 服务器返回 412、网络中断或上传结果不确定时保留本地进度；下次重新读取再合并，不盲目覆盖。
- 常规同步不会复活手机删除的收藏；只有用户再次明确选择“加入书架”才会重新收藏。找不到对应章节的待同步进度继续保留，并在同步状态中计数。

第一次联调前，可通过自己的 WebDAV 客户端另存现有 `backup.proto`，方便检查同步结果。这不是插件写入所需的额外设置。

## 适用范围与限制

- 仅 Komga，不安装原版 Komikku APK 扩展。可读取手机书架，也可直接从 Komga 浏览和获取章节。
- 允许从书库加入收藏及选择已有分类；不提供删除收藏、编辑已有收藏分类、创建分类或管理 Komga 服务端阅读进度。
- 仅支持 HTTPS + 用户名/密码认证，校验证书链和 SAN 主机名；不支持交互式网页登录、客户端证书或绕过证书验证。自签证书可通过自定义 CA 文件配置。
- Komikku 1.14.1 自己会移除 ETag 引号后发送条件请求，严格服务器可能拒绝手机端的请求；插件保留正确的引号，不会修改手机程序。真实 WebDAV 提供商需联调确认。
- 分类中的 `hidden` 数据会保留，但本插件不提供隐藏分类的密码保护；分类和收藏均可在插件内查看。
- 不修改 KOReader 主程序，也不清空普通书籍的历史。已屏蔽本插件漫画的内置历史和阅读统计（日历、时间线）；第三方独立日志需单独适配。
- 连接地址、用户或 WebDAV 目录更换时应先关闭漫画。更换 WebDAV 目标前需清空待同步队列；旧书架另存为 `shelf.previous.proto`，再读取新目标。
- Kindle Voyage 上的实际字体布局、TLS、内存占用、后台预取和原生渲染仍待实机验证。

## 自检和打包

开发自检依赖 Python、`lupa`（含 LuaJIT 2.1）和 `protobuf`。可在当前 Python 环境安装，或放入项目的 `.reference/python/`；插件运行本身不依赖 Python。

```text
python tests/run_tests.py
python tools/build_package.py
```

发布新版本时，将 `_meta.lua` 的版本号改为三段数字，打包后将 ZIP 和 `dist/update.json` 一起上传至对应的 `v版本号` 正式 Release。更新器忽略预发布版；`update.json` 必须与该 Release 的安装包一致。

本地自检覆盖同步协议、冲突处理、网络与下载、缓存、书架与阅读器交互、阅读记录隔离和更新校验。详见 [协议说明](docs/protocol.md) 和 [实施方案](docs/plan.md)。
